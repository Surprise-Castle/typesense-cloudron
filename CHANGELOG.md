# Changelog

All notable changes to this Typesense Cloudron package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [29.0.0] - 2024-12-19

### Added
- Initial release of Typesense Cloudron package
- Typesense 29.0 integration
- Automatic API key generation
- Health checks and monitoring
- CORS support for web applications
- Comprehensive configuration options
- Production-ready Docker setup
- Cloudron manifest with proper metadata
- Build and deployment scripts
- Docker Compose for testing
- Complete documentation

### Technical Details
- Based on Cloudron base image 4.2.0
- Minimum Cloudron version: 7.0.0
- Memory requirement: 512MB minimum, 1GB+ recommended
- Port: 8108
- Data persistence with automatic backups
- Secure API key management
